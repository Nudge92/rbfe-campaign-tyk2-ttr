# TTR 안정화제 후보의 상대 결합 자유에너지 계산 — 마감 보고서

작성 2026-10-05 · 계산 기간 2026-09-12 ~ 2026-10-05 · 단위 kcal/mol (따로 적지 않으면)

## 요약

- 트랜스티레틴(TTR)의 T4 결합 자리에 대해, 실험값이 있는 화합물 3개(앵커)와 새로 설계한 후보 7개를 엣지 17개의 그물로 묶어 상대 결합 자유에너지(ΔΔG)를 계산했다.
- 후보 가운데 **cand0023, cand0030** 두 개가 엣지 구성·적합 방식을 바꾼 12개 조합 전부에서 1·2위였다. 나머지 다섯 후보의 순서는 조합에 따라 바뀌어 정해지지 않았다.
- 같은 계산을 실험값과 맞춰 보면 앵커 3엣지의 RMSE 는 **2.93** 이고, 문헌의 일반적 정확도 1.26 의 2.3배다. 실험 결합력이 같은 두 앵커 사이를 3.87 차이로 계산했다.
- 따라서 후보 순위는 계산 안에서의 순서일 뿐이고, 실제 결합력 순서라고 주장하지 않는다.
- 오차의 원인으로 추정기, 샘플링 길이, 결정수를 차례로 확인했으나 어느 것도 원인이 아니었다. 같은 계보의 파이프라인은 벤치마크 표적 TYK2 에서 RMSE 0.79 를 냈다.

## 1. 무엇을 했나

### 1.1 표적과 목적

TTR 은 사량체 단백질이고, 치료제는 이량체 사이의 T4 결합 자리에 붙어 사량체가 풀리는 속도를 늦춘다(kinetic stabilizer). 결합 자유에너지는 그 효과의 대리 지표다. 이 프로젝트는 생성 모델로 만든 디페닐에터 계열 후보 7개가 알려진 화합물에 비해 얼마나 강하게 결합하는지를 상대 결합 자유에너지 계산(RBFE)으로 평가했다.

### 1.2 그물

![계산 그물](network.png)

- **노드**는 화합물, **엣지**는 두 화합물 사이의 변환 한 건이다. 엣지 하나의 결과가 ΔΔG(A→B) = B 의 결합 자유에너지 − A 의 결합 자유에너지다(음수면 B 가 더 강하게 결합).
- **앵커**는 실험 결합력이 있는 화합물 3개, **후보**는 실험값이 없는 화합물 7개다.
- 엣지를 고리로 이으면 한 바퀴 돈 ΔΔG 합이 0 이어야 한다. 이 고리 닫힘으로 계산의 내부 일관성을 실험값 없이 점검한다.
- 엣지 하나는 복합체(단백질 안)와 용매(물속) 두 환경에서 각각 세 단계(전하 끄기 → 원자 바꾸기 → 전하 켜기)로 계산하고, 같은 계산을 시드만 바꿔 여러 번 반복했다(회차).

## 2. 결과

### 2.1 후보 순위

노드별 값은 그물 전체를 최소제곱으로 푼 것이다(기준 CHEMBL241454 = 0 · 낮을수록 강한 결합). N17 을 넣은 뒤 엣지 구성 3종(전부 / N14 제외 / 플래그 엣지 3개 제외) × 적합 2종(무가중 / 가중) × N17 값 2종 = 12개 조합을 나란히 냈다.

- 기준 화합물보다 강하게 결합하는 것으로 계산된 후보는 cand0023, cand0030 둘뿐이고, 이 둘의 순서는 모든 조합에서 같다. 다만 둘 사이의 차이는 오차 범위 안이다.
- 나머지 다섯은 플래그가 붙은 엣지(N08·N11·N14)를 넣느냐 빼느냐에 따라 값이 크게 움직인다. 플래그 엣지를 빼면 이 다섯은 고리 없이 한 줄로만 이어져 교차 점검이 되지 않는다.

### 2.2 실험과의 비교

앵커의 실험 결합력(Kd1, Gupta 외 2007)은 CHEMBL438498 0.2 ± 0.08 nM · CHEMBL240808 27.0 ± 8.03 nM · CHEMBL241454 27 ± 4.10 nM 이다.

|---|---|---|---|
| N01 | -3.87 | +0.00 | -3.87 |
| N04 | -0.49 | -3.02 | +2.53 |
| N07 | -5.11 | -3.02 | -2.09 |

- RMSE **2.93** · 평균 절대 오차 2.83 (N01 을 5회차로 채우면 RMSE 2.88).
- 비교 기준: 현재 RBFE 의 일반적 정확도 1.26 · 실험끼리의 재현 오차 0.91 (Ross et al., Commun. Chem. 6, 222 (2023)).
- N01 은 실험 결합력이 같은 두 화합물 사이의 엣지라 참값이 0 이다(공시험). 계산값은 -3.87 이다. 사전등재한 기준으로는 '중대 — ΔΔG 를 발표하지 않는다' 등급(2.0 초과)이다.
- 표본은 엣지 3개이고 삼각형으로 묶여 있어 독립적인 것은 2개다.

### 2.3 반복 간 흩어짐과 수렴

- 사전등재한 수렴 기준은 회차 간 표준편차 0.5 이하다. N01~N16 가운데 이 기준을 충족한 엣지는 2개(N01, N07)뿐이다. 16개 엣지의 표준편차는 중앙값 0.95, 최대 4.63 이다.
- λ 창 사이를 끝에서 끝까지 왕복한 횟수가 0 인 레그가 3개 있었다(N11·N14). 이 두 엣지의 값은 신뢰하지 않는다.
- N17 은 창당 8 ns 로 16배 길게 돌렸지만 표준편차가 0.91(로컬 3회차) / 0.82(5회차)로 기준 0.5 보다 크다.

## 3. 오차의 원인으로 확인한 것

| 의심한 요인 | 확인 방법 | 결과 |
|---|---|---|
| 추정기 | 레그 96개에서 BAR·MBAR·TI 비교 | MBAR−BAR 최대 0.03 · MBAR−TI 최대 0.18 — 원인 아님 |
| 샘플링 길이 | N04 를 0.5 → 2.0 ns 로 연장 | 표준편차 1.08 → 0.98 · 오차 +2.53 → +2.65 — 줄지 않음 |
| 교환·λ 사다리 | N17 을 사다리 재설계 후 8 ns × 5회차 | 표준편차 0.82 — 기준 미달 그대로 |
| 결정수 | 6E72 결정수 204개를 넣어 앵커 재계산 | N01 -3.34 ± 0.66 (5회차) — 공시험 여전히 실패 |

결정수 조건은 사전에 기존 계의 물이 결정수 자리를 얼마나 채우는지 재 보았고, 결합 자리 근처 20개 자리 중 19개에 이미 2.5 Å 안에 물이 있었다. 재계산에서는 사슬 15개 중 7개만 끝났다. 나머지 8개는 시딩 단계의 안전 게이트(더미 원자 최소거리)에 두 번 걸려 제외했다(N04 는 2회차, N07 은 0회차). 판단 기준인 N01 은 5회차가 모두 나왔다.

**남은 원인 후보** (측정하지 않음)

- 결합 자리가 두 개이고 서로 영향을 준다(음의 협동성). 실험값이 Kd1·Kd2 두 개이고, 어느 쪽을 계산과 비교할지가 모형에 의존한다.
- 결합 자리가 대칭축 위에 있어 리간드가 두 방향으로 들어갈 수 있다. 계산은 한 자세만 가정했다.
- 리간드가 전하를 띠고(−1), 실험은 pH 4.4 인데 계산은 pH 7.4 기준으로 양성자화했다.
- 계산은 V30M 변이형 구조, 실험은 정상형 단백질이다.

## 4. 벤치마크 표적과의 대조

TTR 계산의 변환 방식과 분석 도구는 앞서 TYK2 로 한 파일럿에서 가져왔다. 그 파일럿의 성적을 나란히 놓는다.

| | TYK2 파일럿 | TTR |
|---|---|---|
| 실험값이 있는 엣지 | 6 | 3 |
| RMSE | 0.79 (95% 구간 0.43~1.05) | 2.93 |
| 평균 절대 오차 | 0.68 | 2.83 |
| 부호 일치 | 6/6 | 2/2 (참값 0 인 N01 제외) |

- 같은 계보의 파이프라인이 벤치마크 표적에서는 문헌 수준의 정확도를 냈다. TTR 의 불일치가 코드 오류 때문일 가능성은 낮아진다.
- 두 계산이 똑같지는 않다. 단백질 힘장(amber99sb 대 ff14SB), 온도(300 K 대 310 K), 창 구성이 다르고, TYK2 는 6개 엣지 중 3개만 HREMD 로 돌렸으며 오차가 전부 음수 방향이다.
- 상세 비교는 `qsar/analysis_20261005_compare/TYK2_vs_TTR.md`.

## 5. 이 보고서가 주장하지 않는 것

1. 후보 7개의 실제 결합력 순서. 순위표는 계산 눈금 안의 순서이고, 그 계산은 앵커에서 실험과 맞지 않았다.
2. 앵커 오차의 원인. 세 가지를 배제했을 뿐 원인을 특정하지 못했다.
3. 그물 전체의 수렴. 대부분의 엣지가 사전등재한 흩어짐 기준을 넘지 못했다.
4. 후보의 약효. TTR 약물의 효과는 사량체 해리 속도이고, 결합 자유에너지는 대리 지표다.

## 6. 다시 한다면

- 후보 엣지를 돌리기 전에 앵커만으로 실험 대비 검증을 먼저 통과시킨다.
- 모든 엣지가 고리 두 개 이상에 들어가도록 그물을 짠다. 고리가 하나뿐인 엣지는 틀려도 가려낼 수 없었다.
- 실험값이 있는 화합물을 3개보다 많이 넣는다.
- 시드 독립성, 스레드 배정, 안전 게이트 같은 절차 문제는 본계산 전에 작은 시험으로 걸러낸다.
- 결합 자세와 양성자화 상태를 계산 전에 따로 검증한다.

### 6.1 그물을 다시 짠다면 — 재설계안 (설계만 · 계산은 돌리지 않음)
