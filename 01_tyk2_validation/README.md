# 1. 파이프라인 벤치마크 검증 — TYK2

실험 결합력이 공개된 표적에서 파이프라인의 정확도를 먼저 쟀다. 실험값 보유 엣지 6개에서
RMSE 0.793 · MUE 0.683 · 부호 일치 6/6. 6엣지 중 3개는 HREMD(24창), 3개는 독립 창(19창)이라
혼합 프로토콜의 성적이며, 오차 6개가 전부 음수다.
