# TYK2 RBFE 파일럿 — 최종 판정 (v2)

> **v1 대비 갱신** — v1은 독립 창 값 기준이었다. 이후 ① edge1·5·6을 HREMD로 재계산 ② edge5·edge6의 HREMD σ 실측(0.210 / 0.952) ③ 노드 앙상블 일관성 확인이 추가됐다. 바뀐 숫자는 v1 값과 나란히 놓았다.

## 판정: 조건부 진행 (유지)

RMSE가 분야 통상 범위 아래이고 부호가 6/6 맞았다. 쓸 수 있다. **다만 조건이 셋에서 여섯으로 늘었다.**

| # | 조건 | 근거 |
|---|---|---|
| **C1** | **2단계 torsion 분석으로 갇힐 edge를 사전 판별할 것** | 이번에 **5/5 적중**. 양 끝이 모두 가동축을 가지면 갇힌다 |
| **C2** | **갇힘이 예상되는 edge는 향상 샘플링을 검토할 것** | 갇힌 edge의 σ가 4.5배 크다 |
| **C3** | **오차막대는 반복 실측으로 낼 것** | 표기오차는 **갇힘이 없을 때만** 자릿수가 맞는다 |
| **C4** | **HREMD를 쓰면 demux 후 g를 재계산할 것** | 디렉터리별 g는 상관시간을 7~46배 과소평가 |
| **C5** | **네트워크 허브를 한 리간드에 몰지 말 것** | edge 5개 중 3개가 ejm_46 공유 → 독립 표본 아님 |
| **C6** | **특이 구조는 1b 힘장 검증을 거칠 것** | 결합각 검증을 3단계 뒤에야 했다 |

### 판정을 "보류"로 내려야 하는가 → **아니다**

내릴 근거로 검토한 것: HREMD σ 0.952(edge6), 표기오차 11.5배 과소평가, A1~A9 철회. **그러나 이들은 전부 "어느 edge가 위험한지 사전에 알 수 있다"는 발견과 함께 왔다.** C1이 5/5 적중했으므로 위험 edge를 가려낸 뒤 다르게 다루면 된다. 판정을 내릴 이유가 아니라 조건을 늘릴 이유다.

## 2. ★★파이프라인 잡음 — 이번 파일럿의 핵심 산출물

## 3. 세 기준선

### (a) 실험 데이터의 한계

`ligands.yml`의 오차 필드가 13개 리간드 전부 값의 **29.2–30.6 %** — 측정값이 아니라 일괄 30 % 가정.

- σ(ΔG) 리간드당 = RT·ln(1.299) = **0.178 kcal/mol**
- **σ(ΔΔG) edge당 = √2 × 0.178 = 0.252 kcal/mol**

★0단계의 "R²max 0.23–0.65"는 재현하지 못했다(재유도값 0.81–0.97). 실험 바닥은 σ(ΔΔG) = 0.252만 쓴다.

### (b) 파이프라인 잡음 — **조건부**

| 조건 | σ |
|---|---|
| 갇힘 없음 (edge5) | **0.210 ± 0.105** |
| 갇힘 2/3 (edge6) | **0.952 ± 0.476** |

### (c) 분야 통상 성능 — ★단서를 달아야 한다

| 출처 | RMSE |
|---|---|
| FEP+ 수동 튜닝 | 1.02 |
| OpenFE 공개 벤치마크 | 1.32 |
| OpenFE 실제 프로젝트 | 1.93 |

★★**샘플링 방식이 다르다.** FEP+는 **REST2**, OpenFE는 **독립 창**이다. 우리 세 edge는 **λ-hopping HREMD**이고, **그 방식으로 낸 대규모 벤치마크는 알려진 것이 없다.** 따라서 (c)와의 대조는 같은 방법끼리의 비교가 아니다.

## 4. 편향 규명의 결론

### 배제된 후보 다섯

| 후보 | 근거 |
|---|---|
| 레그3 수렴 부족 | 4배 연장에 **개선 0**. edge5는 레그3 부담 22.3인데 오차 −0.372 |
| 포즈 · 기하 | 접촉 잔기 **22개 동일** (2단계) |
| 3원환 특유 전하 | RESP 5종 RMSD **0.099–0.129 균일**, 최대 편차가 4/5에서 공통 골격 C4 |
| 전하 방법 전반 | RESP 전환 n=2, **2-edge MAE 0.194 → 0.262 악화** |
| 결합각 · 이면각 | QM/GAFF2 완화 힘상수 **0.855**, **ΔΔG 기여 상한 0.140** |

### 남은 둘 — 검증 수단 없음

**dummy–core 결합** — FEP+엔 해법이 있으나 pmx/GROMACS엔 없다. ★근거도 약하다: 고리 해체가 가장 심한 edge4(−1.087)가 edge3(−1.252)보다 낫다.

**LJ 파라미터** — 실험 물성에 피팅된 값이라 QM 대조가 성립하지 않는다.

### ★HREMD가 새로 확인한 것

edge6은 **정·역이 같은 답으로 수렴한 뒤에도**(HREMD r1 정 +0.171 / 역 −0.184, hysteresis −0.012) 실험에서 **−0.458 벗어난다**. **양방향 공통이므로 샘플링이 아니라 힘장 쪽이다.**

★단 이 진술의 근거였던 hysteresis −0.012는 σ≈0.95 앞에서 무정보다(A2 철회). **오차 −0.458이 3회 평균이라는 점이 더 나은 근거**다.

## 5. 한계 목록

### v1에서 이어지는 것

| 한계 | 근거 |
|---|---|
| 반복이 출발 구조를 공유 | 같은 `solv_ions.gro`, `gen_seed`만 다름 → 구조 편향은 σ에 안 나타난다 |
| σ는 재현성이지 정확도가 아님 | Best Practices: 반복 평균이 편향을 강화할 수 있다 |
| 반복 3회는 권고 미달 | 권고는 > 3 |
| cycle closure의 구조적 맹점 | 노드 편향 δ는 항상 +δ/−δ로 상쇄 |
| 네트워크가 ejm_46에 쏠림 | 차수 3, edge 5개 중 3개 공유 |
| binding pose 미확인 | PLB 정렬본 그대로 |
| 정지 규칙 미통과 | T/t₀ 규칙 2/14 |
| LJ 미검증 | 검증 방법 자체가 없음 |
| R²max 기준선 재현 실패 | 0.23–0.65 재현 못함 |

### v2에서 추가

| 한계 | 근거 |
|---|---|
| **자료가 두 방식으로 섞였다** | edge1·5·6 = HREMD · edge2·3·4 = 독립 창. edge2·3·4를 HREMD로 돌리지 않았다 |
| **HREMD σ를 두 edge에서만 쟀다** | edge5·edge6만 n=3. **edge1은 n=1**이라 σ를 모른다 |
| **σ는 하한이다** | 반복이 `solv_ions.gro`를 공유 → 속도장 잡음의 하한 |
| **λ-hopping은 Procacci 2022가 무효라 지적한 방식** | 논문 사례는 수락률 75–87%인데 이성질체 샘플링 전무. **이 계에서 통한 이유가 장벽 크기(1.2–2.4 vs 수십 kcal/mol)라는 것은 사후 설명이다** |
| **REST2를 쓸 수 없다** | GROMACS에서 알케미컬 FEP와 병용 불가(Bussi 2013). metadynamics는 준비했으나 **재가중과 네트워크 일관성 문제로 실행하지 않았다** |
| **노드 일관성은 "구별 불가"이지 "동일 증명"이 아니다** | 창당 1 ns · 101 프레임 |

### 쓸 수 없는 검산

Reversible binding simulation은 알케미컬 코드 검증의 가장 강한 증거지만 **TYK2에는 못 쓴다** — 다섯 리간드가 전부 나노몰(4.8–250 nM)이라 체류시간이 ~20초로, 관측 가능한 10–100 µs의 10⁵–10⁶배다.
