## 결론

환경 독성 평가용 데이터로 세운 모델을 치료제 후보 설계에 역으로 적용해 후보 7종을 얻었고,
구조적으로 승인약과 동일한 결합 자리 점유를 확인했다. 자유에너지 계산의 신뢰 구간이 순위
판정에 미달함을 대조 조합으로 확인하여, 순위 대신 **7종 전부**를 실험으로 넘겼다.

## 포스터에 담지 못한 것

포스터는 벽 한 장이라 담을 수 있는 분량에 한계가 있다. 이 캠페인에는 포스터에
적지 않은 한계가 더 있고, 전부 아래 전체 기록에 측정값과 함께 적혀 있다.

- **후보를 고른 축이 목표 축으로 전이된다는 근거가 없다 — 0/9.**
  Tox24 결합 치환 %로 학습한 모델 9종을 피브릴 억제 pIC50(실측 64종)에 대해
  따로 평가했고, 아홉 모두 Spearman ρ의 신뢰구간이 0을 포함했다. 자유에너지
  계산의 실패보다 더 상류에 있는 한계다. → [전체 기록 §2-4](PROJECT.md)
- **후보를 모델이 발견했다고는 할 수 없다.** 18,167개 중 화학형 조건
  (디페닐에터 ∩ 카복실산)만 만족하는 것이 118개다. 좁힌 것은 모델이고 화학형을
  정한 것은 승인약 3종과 앵커 9개라는 외부 지식이다. → [§2-3](PROJECT.md)
- **도킹 점수는 이 표적에서 무작위 이하였다** (ROC-AUC 0.3484). 그래서 순위
  지표를 구조 기반에서 리간드 기반으로 교체했다. → [§2-2](PROJECT.md)
- **제출 초록과 그물이 다르다.** 초록은 전하 0층 12노드·19엣지 기준이고,
  최종 캠페인은 전하 −1층 10노드·17엣지다. 두 그물은 분자가 하나도 겹치지
  않는다. → [§6-3](PROJECT.md)
